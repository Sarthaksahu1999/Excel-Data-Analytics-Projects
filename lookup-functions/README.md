# Lookup Functions Assignment in MS Excel

## 📌 Project Overview
This repository contains my **Lookup Functions assignment created using Microsoft Excel**.  
The purpose of this project is to demonstrate how lookup formulas are used to **search, match, and retrieve data** efficiently from large datasets.

---

## 🛠 Tools & Technologies Used
- **Microsoft Excel**
- Lookup Functions:
  - VLOOKUP
  - HLOOKUP
  - LOOKUP
  - INDEX
  - MATCH
  - XLOOKUP
- Data Organization Techniques
- Basic Data Analysis

---

## 📊 Key Features of the Assignment
- Implemented multiple lookup functions for data retrieval
- Combined **INDEX + MATCH** for flexible lookups
- Used **XLOOKUP** for modern and dynamic referencing
- Improved accuracy and efficiency in data handling
- Clean and well-structured worksheets
