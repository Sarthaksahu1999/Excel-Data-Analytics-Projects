# Text Functions Assignment in MS Excel

## 📌 Project Overview
This repository contains my **Text Functions assignment created using Microsoft Excel**.  
The objective of this project is to demonstrate how **text functions** can be used to clean, manipulate, and format textual data efficiently.

---

## 🛠 Tools & Technologies Used
- **Microsoft Excel**
- Text Functions:
  - LEFT
  - RIGHT
  - MID
  - LEN
  - TRIM
  - UPPER
  - LOWER
  - PROPER
  - CONCAT / CONCATENATE
  - TEXT
- Data Cleaning Techniques

---

## 📊 Key Features of the Assignment
- Cleaned and standardized text data
- Extracted specific text using LEFT, RIGHT, and MID
- Combined and formatted text values
- Removed unnecessary spaces using TRIM
- Converted text case for consistency
